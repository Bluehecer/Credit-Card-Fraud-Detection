## 📊 Evaluation Metrics

Our application provides various metrics to assess the effectiveness of fraud detection:

- **Accuracy**: Measures how often the model is correct.
- **Precision**: Quantifies the number of true positive results divided by the number of positive results predicted by the model.
- **Recall**: Measures the model's ability to find all relevant cases in a dataset.
- **F1 Score**: Combines precision and recall into a single score.
